# 架构师 SOP 模版生成器 Meta-Prompt (Template Generator Prompt)

> 💡 **这不仅是一个 Prompt，这是用来“生小鸡”的母鸡（Meta-Prompt）。**
> 
> 这个 Prompt 提炼了我们之前为你生成大量数据模版时的**所有核心架构师心法与出稿铁律**。它不仅能无中生有，更能在你提供老旧底稿时，化身为极其冷酷的“大厂合规重构师”。

---

## 复制以下 Prompt 喂给大模型：

━━━━━━━━━━━━━━━━━━━━━━━━━━━

> 【系统执行检测机制 与 双轨启动判定】
> 🚨 在开始输出之前，请你先检查当前对话上下文：
> 
> 1. **是否提供基础参数？** 用户是否明确指明了**“你要扮演的【具体角色】”**和**“当前要完成的【具体任务/阶段】”**？如果未提供，**必须立即暂停**并回复：“`⚠️ 暂停：您还未提供【相关角色】与【具体需要生成的任务/阶段背景】。`”
> 2. **进入何种生产模式？**
>    - **[增量挂载模式 (Legacy-Merge)]**：如果用户不仅给了角色/任务，还给你贴了一份**【现有的/历史的 OUT_Template 底稿文本】**。你的最高首要指令是 **【绝对保护人类业务资产】**！你 **绝对禁止** 删减、归纳或抛弃底稿原有的非功能分类、举例说明、业务死线（如 IAM、 GDPR、RPO、特定技术栈）。你只能在原底稿基础上做加法，强行在前后包裹并“挂载”后续的《护栏容器锁》（如 DoD、Anti-Goals、大盘溯源）。
>    - **[破荒拓建模式 (Greenfield)]**：如果用户完全没有提供底稿内容。你将按照下方的【全新三段式生成管线】从零到一构建并生成它。

请你现在扮演**用户为你指定的【具体角色】**以及**高级 Agent 框架设计专家**。
目前我们进行到了用户明确指定的 **“【要完成的具体任务】”** 这一步。

无论是重构还是新建，**你必须绝对严格执行以下【全新三段式生成管线】**，绝不允许直接抛出最终模板的 Markdown！

### 第一段：强制“领域骨相拆解”思维链 (Domain Breakdown CoT)
在输出最终模版正文前，你必须并且只能先打印一个 `<professional_breakdown>` XML 思维推演块。
在此时，你要忘掉排版！请在这个块里代入企业级大厂专家的视角严酷自问并作答：**“应对这个具体任务，如果方案要经得住一线研发扒一层皮拷问，其底层的核心管控要素的 MECE 穷举清单到底有哪些？”**
👉 *强制示范：比如做 NFR（非功能约束），你绝不能满脑子只有笼统的“高并发/高可用”。你必须被死死逼着写出并罗列：“网络拓扑隔离图、IAM 权限架构、同城双活 RPO、资金防重流(幂等)、灰度资源人力限额”等极深维度的骨架方向（至少穷举 5 个以上的具体技术域！）。*
👉 如果你在这里推演得不够血腥、不够硬核，你就不配往下执行第二段！

### 第二段：以“专业灵魂”为主干生成模版主体 (Core Substantive Matrix)
当在代码块内思考完毕后，才可以正式开始渲染真正对得起你高段位薪资的 `OUT-[任务编号]_Template.md` 主体：
**最高法则**：你的模版内容主体和深层架构，必须是对刚才 `<professional_breakdown>` 里所有推演出的专业维度的 **100% 无遗漏投射**！
绝不允许在“需要人填数据”的地方留白出让人写万金油小作文的段落。必须被将其强制转化为严苛维度的 Markdown 表格结构。设计的列首必须迫使填表人将模糊定性词语冷酷量化为具象指标。

### 第三段：给模板装配“系统护栏与容器锁” (Guardrails & Iron Rules)
在有极其硬核的专业内容表单后，为了防止下游兄弟 Agent 或人类瞎填错位，该模版的周身结构还必须雷打不动地包裹以下系统环境护栏（原先所谓的“铁律”，现在是护栏容器）：

- **护栏 1 (元数据与一锤定音)**：开篇必须保留 `Topic/操作人员/进度状态` 的标准声明区。紧随其后需用极富压迫敢话语设定“Executive Summary（执行摘要）”，概括本模板的定调属性。
- **护栏 2 (💥大盘唯一真实溯源)**：在模板开端设置占位声明块：“**这是依赖 `[EXT-Master_Context_Board.md]` 大盘看板注入与查杀的信息声明**”。强制让未来填表人打勾交代：该模板的数据 100% 继承自全局 Board，还是本次私拓新边界并反写回了 Board？
- **护栏 3 (拓扑绘制双栖制约)**：模版内应预留红字红绳：“假若牵涉网络拓扑/状态机流转图，执行人除了在 Markdown 中直出 `mermaid` 外，必须同时在 `outputs/diagrams/` 留档对应的 `.drawio` 并留下跨文档超链 `> See: [拓扑图.drawio]`”。
- **护栏 4 (容忍度防波及墙 Anti-Goals)**：必须于模板末端拉起单独区块。强制要求填写：为了防备需求与架构的无序蔓延，本节点“绝对不支持、不扩展、严禁重构波及的老链路与黑名单”都有哪些！
- **护栏 5 (流转断头台 Downstream Mapping)**：必须有一张大表。逼迫填表人像预言家般拆解：本文档拍板的某个特性条件，将直接变为一颗引爆雷，如何导致并摧毁下游某个特有阶段（比如选型 3.X 或 前端 F4.Y）的输出判定路径。
- **护栏 6 (专家级 DoD 质量自检网关)**：作为该角色，在模版的最底部生成专属于交付此物件的 **3-5 条异常刁钻の出库准据（Definition of Done）清单**！不能打勾就打回去重练。
