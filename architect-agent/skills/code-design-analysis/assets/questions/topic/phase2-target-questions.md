# Phase 2 — Topic Scope: Target Understanding Questions
# USER-FACING. Ask one question at a time. Log each Q&A to phases/phase2-target-questions.md.

## Question List

Q2-TOP-01:
Can you describe the topic's scope boundary — which modules, packages, or services are in scope?
(e.g., "Session Management covers auth-service, session-store, and API gateway middleware only")

Q2-TOP-02:
What technology stack and runtime does this topic span?
(e.g., Java 17 / Spring Boot, Node.js / Express — and whether it spans multiple services)

Q2-TOP-03:
How many distinct components are you aware of that participate in this topic?
(Even a rough count: "around 5 classes", "3 microservices", "unclear — needs investigation")

Q2-TOP-04:
Are there known entry points and exit points for the data or control flow in this topic?
(e.g., "starts at the login API endpoint", "ends when session token is stored in Redis")

Q2-TOP-05:
Are there existing architectural documents, ADRs, or diagrams covering this topic?
(Helps understand prior design intent versus what was actually implemented)

Q2-TOP-06:
Has this topic area been problematic or subject to recent changes?
(e.g., "had a security incident last quarter", "being actively refactored by team X")
