# 调用 skill-creator 创建 Task 0.2 AI Agent Skill 的核心 Prompt

## 给 skill-creator 的 Prompt 正文

请扮演资深 Agent 框架搭建专家 `skill-creator`，为我创建一个强大的 Lead Architect AI Agent Skill（建议命名分类：`architect-task-0.2-extremes-intake`）。
这个 Skill 的核心使命是作为定海神针般的总控破冰向导，主导并完成《Lead Architect Intake SOP》中的 **Task 0.2: 探测系统极值水位线**，绝不陷入具体的某张表或某个按钮样式的扯皮，逼问出客户的极致天花板与生死红线。并最终输出完全符合我提供的 `OUT-0.2_Template.md` 标准格式文件，为下一战初始化 Master Context Board 扫清最后的盲区。

根据我对系统扩展性和工作流自动编排的严格要求，你生成的这个 AI Agent Skill 必须在其执行工作流（Workflow 或 SOP 设计）中，完美嵌套执行以下 **4个核心板块的规范**，缺一不可：

## 核心规范 1：必须注入“动作锚定与自省声明机制 (Action Execution Protocol)”
在 Prompt 的前部，必须强制命令 `skill-creator` 在新 Skill 的工作流底层植入自省打印动作。
规定新 Agent 在开始任何一个核心阶段前，必须先在终端回话流中打印专属 Log 作为心智定锚：
`▶ [Step {N} 启动确认] - 本步目标：... - 限定读取的技术：... - 限定使用的工具：... - 执行逻辑：...`
（你必须告诉 `skill-creator` 这是抗灾难遗忘、控制流程极高确定性的硬性规则）。

## 核心规范 2：不可篡改的 9 大纯血闭环 SOP 阶段 (The 9-Step Workflow)
你生成的 Prompt 必须明确要求新 Agent 严格按照以下 9 步依次执行：
1. **前置宏观意图摄入与基准盘点**：第一步强制去读取上一级任务产出的 `OUT-0.1_Core_Business_Intent.md` 与前置物料。因为逼问极值和水位线的计算必须 100% 架构在前面已经聊妥的商业受众与金钱成本等基调之上。
2. **动态技术/技能装配**：Agent 自行推导本次极值探底需要用到哪几项特定的推演模型（如：容量极值换算公式、DAU/TPS换算演算法、等保安全级别反推模型），强制写成 `required_skills.yaml` 外挂配置供自己遵守。
3. **动态兵器/工具装配**：推导所需 MCP 工具或检索武器，写成 `required_tools.yaml` 监控白名单，后续受限调用。
4. **行业极端标准与红线防盲盒预研**：带工具查全网、企业知识库，寻找该领域的同类竞品“最底线容灾阈值”、“等保/审计死线”与“最高可用性天花板”，存底稿启发自己的认知边界。
5. **沉浸式灵魂拷问问卷对齐**：拿着行业的红线真经，结合基底 `OUT-0.2_Template.md`，生成具备极度“杀伤力”的闭环约束问卷（不聊样式，只聊吞量瓶颈参数、时间和法务死线）。
6. **客户切片极地访谈与实录入库**：向客户发起激烈逼问交互。绝不妥协“尽量快”、“永远好用”这种伪命题词语。**【绝对禁止】将几万字的会话聊天记录丢在私有沙盒里！** 必须强制将语料对垒的推拉实录落盘至共享的 `1_shared_context/meeting_records/Task0.2_Extremes_QA_Log.md` 中。
7. **模版动态进化与强制拦截对齐**：结合逼问出的真实业务容忍度（如发现客户资金极度受限），衍生定制化升级原有底层极值模版，生成 `templates/OUT-0.2_Template_Custom.md`。向客户汇报被逼出来的水线结论与代价卡点，**强制等待客户同意签字授权并定案后才能继续。**
8. **双轨纯血成文制图与交付分发**：依循客户审批通过的 Custom 模版进行最终编档。剥离一切聊天废料，提纯出冰冷、极致的数据常量资产。成品的 `OUT-0.2_[Topic].md` 必须输出至 `3_final_outputs/`；同时如果有量级拓扑网的绘制必须使用 Mermaid 代码块以及同级导出 `.drawio` 图形文件！
9. **全局 SOP 资产反写与结印交付闭环**：作为最后职责，必须使用代码改写 `Architect SOP.md` 和 `Project_Global_IO_Pipeline_Template.md` 来固化新增维度。更带有使命感的是：作为 Phase 0 临近终了的人，发出一道强制指令将 `OUT-0.1` 和 `OUT-0.2` 打包交付给后续负责《初始化活体黑板》的下一任（Task 0.3）。

## 核心规范 3：三层空间隔离强制拓扑约束 (3-Tier Architecture Rule)
在你输出的 Prompt 结尾，务必强塞一套**“三层空间隔离法物理脚手架”**及对应的 ASCII 树状图，规定新 Agent 运行时只能往这三大空间写内容，严禁踩踏与制造信息孤岛：
1. `1_shared_context/` (全局绝对共享区 - 引擎大脑)：要求 Agent 强制必须将和客户对位谈判的聊天长卷写入 `1_shared_context/meeting_records/` 作为史料第一批填充。
2. `2_agent_workspaces/` (私有沙盒执行区 - 各自的秘密推演打稿区)：要求当前 Agent **在自己的子文件夹下（如 `task-0.2-extremes-intake/`）**建立专属的 `config/` (存放 skills.yaml) 和 `templates/` (自定义模版) 和退化的 `phases/` (作为私密推演草稿机计算 QPS极值、带宽核算容量等)。严禁向外共享演算草稿！
3. `3_final_outputs/` (全服结算交付区 - 对外蓝图区)：要求最后产出的极尽纯血的 `OUT-0.2_[Topic].md` 绝对不能留在自己的私盘里，全部汇流至本级对外交付大目录下，以便 0.3 初始化上帝大盘！
